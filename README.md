# Stratascratch_Sql

For the past six months, I have been consistently practicing coding and database-related questions. However, I did not maintain a proper record of the types of questions I solved or the queries I wrote.

This repository is a collection of all those questions and queries, organized to track my progress and learning journey.
I have primarily practiced on StrataScratch, a platform similar to LeetCode, with the added advantage that many questions are tagged with the companies where they have been asked. Although not all questions have company labels, this feature provides useful insight into real-world interview patterns.
This repository represents my learning journey and ongoing effort to improve my problem-solving skills.
